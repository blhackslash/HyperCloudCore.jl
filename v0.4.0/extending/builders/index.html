Config-Driven Builders

HyperCloudCore.Builders turns flat, namespaced parameter dictionaries into the numerical objects of the package. It exists so that a wrapper (or a test suite) does not have to re-implement the symbol-to-type mapping for every scheme, tableau, limiter and strategy, and so that this mapping is updated together with the types it names.

using HyperCloudCore, HyperCloudCore.Builders

context = Dict{Symbol, Any}(:Type => Float64, :D => 1, :M => 1, :Equation => eq,
                            :ExplicitSources => (), :ImplicitSources => ())
context[:WeightConf] = Dict(:name => :exponential, :range => 2.5, :alpha => 1.0)

context[:Domain]  = build_domain(Dict(:domain => :rectangular, :mins => (-1.0,), :maxs => (1.0,), :periodic => true), context)
pg                = build_particle_grid(Dict(:Ns => (200,), :mover => :lagrangian), context)
context[:Flux]    = build_flux(Dict(:name => :Rusanov), context)
context[:Limiter] = build_limiter(Dict(:name => :none), context)
context[:MOOD]    = build_mood(Dict(:criterion => :U2, :strategy => :EPD1, :delta_relax => 1e-4), context)
context[:Scheme]  = build_scheme(Dict(:name => :MUSCL, :order => 3), context)
context[:Tableau] = build_tableau(Dict(:stepper => :RK3), context)
ts                = build_timestepper(context)
adaptivity        = build_adaptivity(Dict(:enabled => true), context)

Every builder is build_x(conf::Dict, context::Dict) and dispatches on Val(conf[:name]) (or the namespace's selector key). Adding a variant means defining one more method:

Builders.build_flux(::Val{:HLL}, conf::Dict, context::Dict) = MyHLLFlux()

The physics side is deliberately not here: PDEs, initial conditions and source terms are built by the wrapper, which then fills context[:Equation], [:D], [:M] and the source tuples before calling into this module.

Reference

HyperCloudCore.Builders — Module
HyperCloudCore.Builders

Config-driven constructors for the numerical objects of HyperCloudCore. Every builder has the signature build_x(conf::Dict, context::Dict) and dispatches on Val(conf[:name]) (or a similar selector key), so a wrapper package (or a test suite) can add its own variants by defining another Val method. This module owns the numerics side of the configuration: schemes, fluxes, limiters, MOOD, tableaus, time steppers, weight functions, domains, boundary conditions, grid movers, volume estimators, adaptivity and the particle grid. The physics side (PDEs, initial conditions, source terms) belongs to the wrapper.

The context::Dict{Symbol, Any} carries everything that is already built. Builders read:

Namespaces

Configuration dictionaries are flat with namespaced keys (:Scheme_name, :Time_stepper, …); PDEStudioCore.extract_namespace(params, :Scheme) yields the conf dict a builder expects. Keys used:

  • Grid: domain, mins, maxs, Ns, periodic, bc (or bc_map), randomness_factor, seed (or SEED), mover, mover_alpha, mover_amplitude, volumes, volumes_degree, volumes_samples_per_dx
  • Weight: name, range, alpha
  • Flux: name; Limiter: name, mode; MOOD: criterion, strategy, delta_relax
  • Scheme: name, order, MLS_order, upwind_alg_nd
  • Time: stepper, reset_orders_per_stage, full_search_per_stage
  • Adapt: enabled, max_gap, min_gap, clearance, samples_per_dx, exclude_reduced_order

HyperCloudCore.Builders.build_particle_grid — Method
build_particle_grid(grid_conf, context) -> ParticleGrid

Requires real_type(context), [:D], [:M], [:Domain], [:WeightConf]. Stores :max_dx in the context, builds the weight function, the grid mover and the volume estimator from the same Grid namespace, and sets context[:Grid].

HyperCloudCore.Builders.build_tableau — Method
build_tableau(time_conf, context) -> IMEXButcherTableau

Selector :stepper: :Euler, :RK2 (SSP), :RK2Ralston, :RK3 (SSP), :RK4, :ARS222, :ARS233, :PRSSP3, :SSP332, :IMEXEuler. Explicit tableaus are returned as IMEXButcherTableaus with a zero implicit part.

HyperCloudCore.Builders.build_timestepper — Method
build_timestepper(context; time_conf = Dict()) -> GeneralRKTimeStepper

Requires context[:Equation], [:Scheme], [:MOOD], [:Tableau], [:ExplicitSources], [:ImplicitSources]. Optional Time keys: reset_orders_per_stage, full_search_per_stage; the volume estimator comes from context[:VolumeEstimator] if set (otherwise the stepper default).

HyperCloudCore.Builders.real_type — Method
real_type(context) -> DataType

The floating-point type of the run: context[:T], or the legacy key context[:Type], else Float64.
