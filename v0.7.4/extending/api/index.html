API Contracts

HyperCloudCore is extended by subtyping one of its abstract types and implementing a few methods. This page lists, per extension point, what is required and what is optional, followed by the reference for every method in API.jl.

Import the methods you extend (import HyperCloudCore: flux, max_eigenvalue, ...) or qualify them (HyperCloudCore.flux(...) = ...).

A new PDE (HyperbolicPDE{D, M, T})

MethodRequiredUsed by
flux(eq, U) -> Flux{D,M,T}alwaysall schemes
max_eigenvalue(eq, U, d) -> TalwaysRusanov flux, CFL estimate
velocity(eq, U, d) -> SMatrix{M,M,T}for Upwind (Tiwari, Praveen), WENO, UpwindFluxadvection speed / Jacobian
evaluate_nc_jump(eq, f_L, f_R, dist) -> Fluxfor non-conservative PDEsMUSCL, Upwind Classic
fluid_velocity(eq, U) -> Space{D,T}for Lagrangian moversLagrangianMover, ScaledLagrangianMover
max_eigenvalue(eq, U, d, shift) -> Toptionalexact relative wave speed on moving grids
is_admissible(eq, U) -> BooloptionalMOOD's physical admissibility detection (default: all components finite)
prim2cons, cons2primoptionalconversions (identity by default)

Write PDE-dependent code against these methods rather than against fields of eq. On moving grids the schemes receive the PDE wrapped in an ALEFrame, and only the API methods are forwarded through that wrapper.

A new source term

KindMethods
AbstractExplicitSourceTermevaluate_source(st, U, i, pg, t)
AbstractImplicitSourceTermevaluate_source(st, U, i, pg, t), implicit_solve(st, U_in, γ, i, pg, t); optional pre_solve_update!(st, Y, pg, t)

implicit_solve must return the solution $U$ of $U - \gamma S(U) = U_{\text{in}}$ for the particle i.

A new spatial scheme (DivergenceInterpolator)

MethodRequiredPurpose
(interp)(eq, i, f_i, nb_slice, pg, ib, strategy::MOODStrategy) -> Statealways$\nabla\cdot F$ at particle i
_extract_order(interp) -> Intalwaysmaximum consistency order
update_size!(interp, N)always (may be a no-op)grow internal per-particle buffers
update_content!(interp, i, f_i, nb_slice, pg, ib)optionalpre-gather pass (e.g. cache gradients)
_divergence_degree(interp) -> IntoptionalMLS degree for the CFL estimate (default: the order)
_order_reach(interp, strategy) -> Intoptionalhops over which fluxes depend on neighbours' orders (default 0)
has_cached_gradients(interp), cached_gradients(interp)optionalenables MOODu2's curvature test

Inside the functor:

  • Read the particle's order from pg.core.particle_orders[i] (the consistency order) and lower it locally if the neighbourhood is too small.
  • Neighbour states are in ib.f[k] and differences in ib.df[k] for k ∈ nb_slice; pg.neighbor.indices[k] is the neighbour's particle index.
  • Write per-neighbour scratch only to slots k ∈ nb_slice of ib (they are disjoint between particles, which makes the passes thread-safe).
  • If the scheme caches per-particle data in update_content!, _order_reach must cover how far that data is read: MUSCL reads neighbours' gradients, so its reach is at least 1.

Define the optional hooks after the scheme's type, next to the scheme; the time-stepping files only refer to the abstract type.

A new MOOD criterion or strategy

See Multi-Dimensional Optimal Order Detection (MOOD) for the signatures of the criterion functor, _get_interface_orders and trigger_halo!.

A new grid mover, boundary condition or weight function

  • Grid mover: grid_velocity(mover, eq, p, U, pg, t) -> Space{D,T}; see Moving Grids (ALE).
  • Boundary condition: functor (bc)(pg, rhos_buffer, tag, ts, eq, t); see Boundary Conditions.
  • Weight function: functor on the squared distance plus get_cutoff; see MLS Weight Functions.

HyperCloudCore.is_admissible — Method
is_admissible(eq::HyperbolicPDE, U::State) -> Bool

Physical admissibility of a state (the PAD of MOOD): a MOOD time stepper drops the order of a particle whose candidate state is not admissible, whatever its criterion says. The default only rejects non-finite states (NaN or Inf); systems with an admissible set (e.g. positive density and pressure for the Euler equations) add a method. Runs inside kernels.

source
HyperCloudCore.max_eigenvalue — Method
max_eigenvalue(eq::HyperbolicPDE, U::State, d::Int, shift::Real)

Maximum absolute eigenvalue of the flux Jacobian along d after shifting the spectrum by -shift (used by ALEFrame on moving grids). The default max_eigenvalue(eq, U, d) + |shift| is a safe bound; PDEs whose spectrum is known can override it with the exact max |λ - shift| to recover the full dissipation reduction of a Lagrangian frame.
